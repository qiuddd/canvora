# Canvora

**一个跑在你自己的 Windows 电脑上的无限画布 + AI 创作 + 视频剪辑工作台。**

把图片和视频摊在一块可以无限拖拽缩放的画布上，在画布上直接调用 AI 接口生成新的图片和视频，把画布上的素材拖进时间轴做基础剪辑，最后导出一条成片。**所有数据都留在你的电脑上**，不经过任何第三方服务器（除了你自己填进去的 AI 接口）。

## 这台电脑能扛住什么

Canvora 是**针对你这台电脑专门设计**的，这些数字决定了所有技术选择：

| 部件 | 实测 | 意味着什么 |
|---|---|---|
| 显卡 | RTX 4060 Laptop，**8 GB 显存** | 图片放大、视频放大、补帧都能跑，但同一时刻只能跑一个 |
| 内存 | **16 GB** | **这是最硬的瓶颈**。所以本地 AI 任务严格排队，视频处理分块进行 |
| 磁盘 | C 盘只剩 66 GB，**F 盘 288 GB、G 盘 244 GB 空闲** | 所有大文件都放 F 或 G 盘，绝不占 C 盘 |
| 已装 | Node 22、Python 3.11、ffmpeg 7.1、git | 可以直接开工 |

**速度预期（实话实说）**：

- 一张 1024×1024 的图放大 4 倍：约 10~30 秒
- 一段 1080p 10 秒视频放大到 4K：约 4~6 分钟（用快速模型）到 20 分钟以上（用高质量模型）
- 补帧到 60fps：1 小时素材约需 40 分钟到 1.5 小时

这不是实时预览式的功能，是后台批处理，界面上会显示进度和预计剩余时间。

## 开始使用（开发完成后的流程）

### 第一次使用

1. 双击 **`启动.bat`**
2. 浏览器自动打开，出现引导页
3. **选一个放数据的文件夹** —— 引导页会列出各磁盘的剩余空间，**默认选中空间最大的盘**（推荐 F 盘），不要选 C 盘
4. 引导页会检查 ffmpeg 和本地 AI 工具是否就绪，缺了会提供一键下载
5. 去「设置 → 模型与接口」里填你的 AI 接口密钥

### 日常使用

双击 `启动.bat` → 浏览器操作 → 用完关掉命令行窗口。

**注意**：这是"本地网页应用"，不是双击就开的软件，所以每次都要先启动。这是为了开发迭代快而做的取舍，将来如果需要，可以再包一层外壳变成真正的桌面软件（见 PRD 的 P2 阶段）。

## 你需要准备的 AI 接口

Canvora 本身不含任何 AI 模型，**你需要自己去服务商开通接口并填进来**。程序里可以自由添加任意服务商，下面是国内个人能开通的推荐清单。

| 服务商 | 能做什么 | 个人能开通吗 | 价格量级 |
|---|---|---|---|
| **阿里云百炼（通义万相）** | 生图 + 生视频 + **首尾帧**（一家全包） | ✅ 个人实名即可，还送 90 天免费额度 | 图 0.14~0.54 元/张；视频 0.10~0.73 元/秒 |
| **智谱 bigmodel** | 生图 + 生视频 + 首尾帧 | ✅ 个人实名即可 | **最便宜**：图 0.06 元/张，视频 1 元/次 |
| **火山引擎（即梦/豆包）** | **生图**（Seedream） | ✅ 图片可以 | 图约 0.2 元/张 |
| **MiniMax 海螺** | 生视频（带原生音频，4~15 秒） | ✅ 个人实名 + 微信充值 | 768P 约 $0.08/秒 |
| **DeepSeek** | 只能做**文本**（写提示词、AI 扩写） | ✅ 有 key 即可 | 约 1~2 元/百万字 |

**建议先开通「阿里云百炼」**，一家就能覆盖生图、生视频、首尾帧，还能先用免费额度试。想省成本再加「智谱」。

### ⚠️ 三个重要的现实限制（别被网上的教程骗了）

1. **火山引擎的 Seedance 视频 API，个人拿不到。** 官方明确只面向完成企业认证的主体，个人用户不在申请范围内；解锁完整能力还要签保底协议 + 支付预付款 + 百万元级保证金。所以"用 Seedance 生视频"这条路对个人不通，**视频生成请走通义万相 / 智谱 CogVideoX / MiniMax**。
2. **可灵 Kling 的 API 需要白名单人工审核**（要提交《API接入需求说明书》），且预付费标准包起步约 700 美元。个人自用阶段不划算。
3. **DeepSeek 不能生图、不能生视频**，它只提供文本能力。别指望用它出图。

### ⚠️ 关于密钥安全，一句实话

**保存在你这台电脑上的密钥无法做到真正保密。** 任何存在于本机文件里的密钥，理论上都能被读取。

请务必：
- **只填写在服务商后台设置了消费上限的子密钥**，不要用主账号密钥。
- 如果某个密钥不小心泄露给别人看过（比如发在聊天里），**立刻去服务商后台删掉它重建一个**。

Canvora 会加密保存密钥，并且保证：密钥不会出现在界面默认状态、不会出现在日志文件、不会被提交到代码仓库。

## 为什么不用现成的工具

调研过的方案和否决理由（详细版本见 PRD 第 6 节）：

| 方案 | 为什么不直接用 |
|---|---|
| **tldraw** | 技术上最合适（唯一自带视频元素的画布 SDK），但 2025 年 9 月起改成自定义许可：**生产环境必须买 license key，免费档强制带水印且禁止商用**，商业授权约 6k 美元/年量级。和"不花钱"直接冲突 |
| **Excalidraw** | MIT 免费，但没有视频元素，视频只能靠 iframe 绕，播放行为会和画布缩放打架 |
| **Konva 做整个画布** | 画布上的节点里有输入框、下拉框、滑块、播放器，这些用普通网页元素是免费的，用画布库画就得自己从头造输入框和滚动条，纯亏。（Konva 只在**时间轴**那一层用） |
| **你的帖子里那个 Infinite-Canvas**（hero8152） | 许可证是自定义的：**禁止商用，且二次开发必须开源并署名**；作者已宣布停更；代码是 786KB 的无类型单文件，改不动 |
| **Video2X** | **AGPL-3.0 许可证会传染**。你自己用没事，但将来想分享给别人就会逼你开源整个 Canvora。改用 Real-ESRGAN（BSD-3）+ RIFE（MIT）自己串流水线，功能一样 |
| **跑本地 AI 大模型** | 你只有 16GB 内存 + 8GB 显存，本地跑大模型会和剪辑任务抢资源。云端接口便宜且质量更高 |

**最终路线**：自研画布（借鉴 MIT 项目的设计但不抄代码）+ 云端 AI 接口 + 本地放大/补帧 + ffmpeg 剪辑导出。

## 已经踩过的坑（写在文档里避免重踩）

这些都是调研阶段查证出来的、会真实卡住开发的问题：

- **Windows 11 已经移除 `wmic` 命令**，取系统信息要用 PowerShell 或 Node。
- **ffmpeg 的滤镜串里逗号必须转义**（`between(t\,3\,8)`），否则解析失败。
- **LUT 文件的路径在 ffmpeg 滤镜里必须用正斜杠**（`file=C:/...`），用反斜杠会**静默失败**，不报错但没效果。
- **`atempo` 音频变速不能超过 2 倍**，10 倍速必须串联成 `atempo=2.0,atempo=2.0,atempo=2.5`。
- **慢放要先补帧再拉长**，顺序反了会插出一堆重复帧，画面卡成 PPT。
- **4K 视频抽帧会产生巨量临时文件**：PNG 一帧 20~25MB，30fps 一分钟就 45GB。必须用 JPEG 且分块处理完立即删。
- **视频放大完必须能从原视频复制音轨**，否则导出的片子没声音。
- **没有音轨的片段在拼接时必须补静音**，否则 ffmpeg 的 concat 会直接失败。
- **mp4 的尾帧不能用 `-sseof -0.1` 取**，那受关键帧对齐影响，可能不是真正的最后一帧。
