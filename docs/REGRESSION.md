### 本轮修掉的问题

1. **导入必然失败**：原实现读取 `File.path`，这是 Electron 专有属性，浏览器里永远是 `undefined`，所以拖入图片/视频只会弹「浏览器无法读取文件路径」。改为把文件字节流式上传到后端。
2. **节点跟着鼠标跑**：原来整个节点卡片都绑定了 pointerdown。改为只有标题栏能拖动，正文和端口都阻止冒泡。
3. **连线没有落点校验**：原来是「点输出口 → 点覆盖按钮」的模拟交互。改为真实的拖拽 + `elementFromPoint` 命中测试 + 端口类型校验 + 环检测 + 非法端口灰显。
4. **连线在快速拖拽时丢事件**：事件监听原来在 `useEffect([connecting])` 里注册，pointerup 可能早于 React 提交而丢失。改为挂载时注册一次、用 ref 读取最新状态。
5. **新建节点互相遮挡**：原来按 28px 递增摆放，节点宽 260px 会压住上一个节点的端口。改为网格排布。
6. **`npm run dev` 在 Windows 起不来**：`a & b` 写法下 cmd 会阻塞在第一个命令。改为 `scripts/dev.mjs` 同时拉起两个进程（不引入新依赖）。
