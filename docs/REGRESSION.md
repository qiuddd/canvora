### 本轮修掉的问题

1. **素材库拖拽失效（我自己引入的回归）**：重写素材库时把 `dataTransfer.setData` 弄丢了，导致从素材库拖到画布/时间轴都没反应。已修复并实测。
2. **`setPointerCapture` 抛异常会中断整段拖拽**：它原来排在挂监听之前，一旦失败（合成事件、异常指针）整个拖拽逻辑就不执行。已改成先挂监听、捕获失败也不影响功能。
3. **时间轴首段容易留缝**：空轨道拖入时按落点定位会留下看不见的空隙，播放头拖到开头就是黑屏。现在空轨道首段自动贴起点。
4. **同轨道片段重叠**：现在自动往右推到不重叠。
5. **导出任务被接口拒绝**：`POST /api/jobs` 原本要求 `assetIds` 非空，而导出成片的输入是整条 EDL。已放行。

### 与文档的偏差（需要你知道）

- **时间轴用 DOM 实现，没有用 Konva**。PRD 6.6/TASKS 6.1 建议 Konva。选择 DOM 的理由：片段数量在几十个量级时 DOM 完全够用；而拖拽交互要与画布共用同一套已验证的指针事件写法，引入 Konva 会多一层坐标与事件适配；也避免再加一个依赖。如果你要求严格按文档走，我可以再换成 Konva。
- **AGENTS.md 4.6 关于 LUT 路径的说明已修正**：只把反斜杠换成正斜杠不够，`lut3d=file=C:/x.cube` 会被 ffmpeg 在冒号处切开。实测唯一可用写法是 `lut3d=file='C\:/Canvora/luts/x.cube'`（正斜杠 + 冒号转义 + 整体单引号）。
