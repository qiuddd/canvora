### 修掉的 bug

1. **补帧只出 0.13 秒残片（严重）**：`buildRifeArgs` 把 `-n` 当倍率传，但 RIFE 的 `-n` 是**目标总帧数**。
   传 `-n 2` 时它只输出 2 帧左右 → 成片 0.133 秒 / 8 帧。改成传「这一批输入帧数 × 倍率」后实测 1572 帧、26.2 秒。
   单测同步改成断言目标总帧数语义。修复前产生的坏产物已从素材库删除。
2. **对话"不能读图"是我的误判**：上一轮我用 `max_tokens: 60` 测试，模型把预算全花在 `reasoning_content` 上，
   `content` 为空就误以为不支持 vision。查官方文档确认 `deepseek-flash` 支持图片，去掉 token 限制后实测能准确读出画面内容。
   后端现在把 `finish_reason=length` 区分开来并给出「回答被长度截断，请重发」的中文提示，不再误报。
3. **时间轴剪辑语义纠正**：产品所有者指出拖边缘应该是**裁剪**而不是变速。已把默认模式翻转为裁剪，
   变速改为双击/右键显式切换，徽标区分「保留 6.2s」与「4.22x」。
4. **检查器提示没跟着默认值走**，仍显示「变速模式」——已修。
