### 本轮修掉的问题

1. **工作区状态并发覆盖（数据完整性 bug）**：状态是单文件 JSON，后台任务写产物 + 接口写数据会互相覆盖。实测「刚建好的分组被任务写回旧状态冲掉」。已在 `workspace.ts` 引入按工作区的串行锁 `mutateWorkspace`，所有写操作都在锁内完成「读→改→保存」；`jobs.ts` 的素材登记也改走同一入口。修完重测分组不再丢失。
2. **素材哈希整块读文件**：放大后的视频可能几百 MB，`readFile` 会一次性占掉同样大的内存。改成 `createReadStream` 分块算 sha256。
3. **刷新后画布看起来是空的**：项目内容其实存在服务端，但界面回到项目列表会造成「我的东西没了」的错觉。现在用 localStorage 记住上次项目，刷新直接回到原地。
4. **「导出首尾帧」只出一张**：后端任务按 `position: first|last` 单个执行，前端现在一次提交两个任务，每个视频都能拿到首帧和尾帧两张图。
